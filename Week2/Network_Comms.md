### Network

A network is a collection of devices connected to share resources and communicate with each other.

Key functions of a network:

- Enable communication between individuals and groups
- Facilitate data sharing across different platforms
- Provide access to resources and information online
- Support collaboration and interaction in various fields

***Clients*** : They initiate request for services and resources. They are the primary users of network, interacting with various servers for information access and functionalities they need.

***Servers*** : They respond to client requests and provide resources.

### Types of Network

***LAN*** (Local Area Network): Local network for home and office.

***WAN*** (Wide Area Network): covers a broad area, often connecting multiple LANs.

***Cellular Network*** : provides mobile connectivity through towers, that allow mobile devices to connect to the internet or make calls.

***Wi-Fi networks*** : Wi-Fi offers high-speed internet access and is commonly used in homes. It allows multiple devices to connect without the use of wires.

***Bluetooth network*** : for short-range communication, suitable for connecting devices like headphones or smartwatches.

### Host Connectivity

To connect to the internet, the host requires several components. They are:

- IP Address: Unique Identifier for each host on the network, like a home address for devices.
- Network Interface: Hardware or software that connect a host to the network
- Protocols: TCP/IP governs data communication between hosts, making sure that the device can understand each other.

### Network Infrastructure Devices

Network infrastructure devices are like traffic wardens, directing vehicles (data packets) to different parking lot or to a different floor in the same parking lot.

***Router*** : A router directs data packets to different networks

***Switch*** : A switch connect devices within a local network and manages traffic

### Network Data

Network data are a stream of small packets of information that are transmitted between devices. Key points are:

- Data can vary in size, with video data being larger than text data.
- Different types of data include text, audio, and video.
- Transmission methods can include wired and wireless technologies.

***Data Transmission Process*** : This process is the bread and butter of network data, it helps break down large data into small packets so it can be sent quickly and reliably.

***Network Transmission Speed*** : is the speed at which data is transmitted. There are factors that can affect the transmission speed, they are:

- Distance: the further from the router, the slower the speed.
- Interference: Physical obstacles and other electronics can disrupt the signal.
- Bandwidth: The amount of data that can be transmitted.

### Network Documentation

Network documentation is essential for management and troubleshooting, enabling technician to track configurations and resolve issues. Key points:

- Facilitates management of network configurations
- Aids in troubleshooting network issues
- Enhances communication among team members
- Provides a historical record of changes
- Supports compliance and auditing processes

***Types of Documentation*** :

    - Network Diagrams : Visual representations of the network structure.
    - IP address lists: Catalogs of assigned IP addresses for devices.
    - Policies: Guidelines that govern network usage and security.

***Benefits of Documentation*** :

    - Improves efficiency by providing clear guidelines
    - Reduces downtime through quicker problem resolution
    - Facilitates better communication among team members.
