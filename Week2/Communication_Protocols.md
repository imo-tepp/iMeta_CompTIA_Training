# Introduction to Network Communication

## Learning Objectives

- Describe network communication protocols and standards
- Compare the OSI and TCP/IP models.
- Explain the functions of Layer 1 and Layer 2 in an Ethernet network.

### OSI and TCP/IP Model

The ***OSI Model*** has 7 layers, with each layer serving a specific function:

    Physical - hardware connections
    Data Link - data frame transfer between devices
    Network
    Transport
    Session
    Presentation
    Application

Whereas the ***TCP/IP Model*** has 4 layers, with some of the layers combined to simplify the communication process:

    Link
    Internet
    Transport
    Application

## Questions & Answers

### 1st Set

1. What does OSI stand for in the OSI model?
    - Open Systems Interconnection
2. How many layers are there in the OSI model?
    - 7
3. Which layer of the OSI model is responsible for end-to-end communication?
    - Transport Layer
4. In the OSI model, which layer is responsible for routing packets?
    - Network Layer
5. Which model is more widely used in practical networking, OSI or TCP/IP?
    - TCP/IP

### 2nd Set

1. What is Layer 1 in networking?
    - The physical layer of the OSI model
2. Which of the following is an example of Layer 2 technology?
    - Ethernet
3. What type of devices operate primarily at Layer 2?
    - Switches
4. What is the role of MAC addresses in Layer 2?
    - To identify devices on a local network
5. Which layer is responsible for error detection and correction?
    - Layer 2
6. What does Layer 1 include?
    - Cables and connectors

### 3rd Set

1. What is the primary purpose of the TCP/IP model?
    - To provide a framework for internet communication
2. Which layer of the OSI model corresponds to the Internet layer of the TCP/IP model?
    - Network Layer
3. How many layers are there in the OSI model?
    - 7 layers
4. What is a key difference between the TCP/IP model and the OSI model?
    - TCP/IP has four layers, OSI has 7 layers.
5. What is a similarity between the TCP/IP and OSI models?
    - Both standardize communication processes

### 4th Set

1. What is the primary function of layer 1 in the OSI model?
    - To transmit raw bitstreams over a physical medium
2. Which layer of the OSI model is responsible for error detection and correction?

3. What is a key difference between layer 1 and layer 2?

4. Which of the following is an example of layer 2 technology?
    - Wi-Fi/Ethernet
5. What does layer 2 use to identify devices on a network?
    - MAC addresses
6. What is Ethernet primarily used for?
    - Transmitting data over long distances
7. What type of cable is typically used for Ethernet connections?
    - Twisted pair cable
8. True or False: Ethernet can only be used for wired connections.
    - False
9. What is the maximum length for a standard Ethernet cable run?
    - 100 meters
10. Which device is commonly used to connect multiple Ethernet devices?
    - Switch
11. What does the term 'MAC address' refer to in Ethernet networking?
    - A unique identifier for network devices
12. What is one advantage of standards for organizations?
    - Improved quality of products or services

    - By streamlining processes
