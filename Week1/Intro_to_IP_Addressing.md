# Introduction to IP Addressing

## Learning Objectives

- Describe the basic concepts of **IP addressing** and it's significance.
- Identify and explain the different **IP classes** and their uses.
- Explain the role of a **default gateway** in a network and it's necessity.
- Describe the **subnet masks** and their function in IP addressing.

### IP Address

A Unique identifier assigned to devices on a network, enabling devices to communicate.

### Default Gateway

A device that routes traffic from local network to others, enables external communication. Without it, device can't access the **Internet**.

### Subnet Mask

A number that defines the network and host portions of an IP address, helps organize networks by defining how many devices can be on the network, ensuring efficient communication and resource management.

Subnet mask works by breaking the network into smaller, manageable segments, allowing for better management of IP addresses and improve network performance. For example:

- Subnet Mask 255.255.255.0 is commonly use for Class C networks, this number allows 256 addresses to be allocated within the network.

### IP Classes

IP Addresses are categorized into classes(A,B,C,D,E) based on size, that help determine how many devices can connect to a network.

- Class A: Supports large networks with many hosts, ideal for big organizations.
- Class B: Support medium-sized network, ideal for universities and large businesses, provides flexibility and scalability for growing organizations.
- Class C: Support Small networks, ideal for small businesses and home networks, allows limited number of hosts but ensure efficient communication and management.
